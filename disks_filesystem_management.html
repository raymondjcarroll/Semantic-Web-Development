Disk & Filesystem Management

Goals of Disks and Filesystems

It's important to be able to save work that is done within a system. That's the value of a file, and it can save anything imaginable. Part of system administration is:

  • Keeping up with these files
  • Making these files accessible
  • Keeping these files as secure a possible, and maintaining as little access as possible

What is a Filesystem?

A file system is a collection of files that are organized together. A file system is not too different than a filling cabinet.

In UNIX, filesystems are partitions of a disk that can get mounted to look as it's a folder in another filesystem.

For example, the folder gru can be a folder in the root directory and have the sub-folders kevin and stewart. kevin and stewart can be on different disks that gru and than each other.
